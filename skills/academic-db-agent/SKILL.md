# Academic DB Agent (optional example)

CentricMem’s **core skill** (`centricmem-agent`) now owns structured corpus projects. `centricmem ambient` lists them as `corpus=<slug>`. Search, filter, show, and index with `-p <slug>` as that skill says.

This file remains only as an L1 adapter **example** for other domains. You do not need it installed to use an academic markdown tree already junctioned under `imported/academic/`.

Details: `centricmem-agent` [REFERENCE.md](../centricmem-agent/REFERENCE.md) (Structured corpus).
